1. Use an EmDash site with Registry sandbox support, [DinkusKit Commerce](https://plugins.emdashcms.com/plugins/@dinkuskit.com/dinkus-commerce), and a DinkusKit store template release that includes the sign-in and account pages.
2. Pick an email sender in **Settings > Email**. Sign-in codes go through it.
3. Install DinkusKit Accounts. Shoppers can sign in from your store's account page.
